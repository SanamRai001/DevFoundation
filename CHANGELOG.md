# Changelog

Documented changes to the DevFoundation starter and CLI.

This repository has **not yet declared a stable v1.0 release**. The features below are available on the development branch until reviewed and merged. A GitHub release should only be tagged from a verified `main` commit.

## Unreleased — real-world validation and easier access

- Optional `--example notes` teaching project with React, Express, Zod and PostgreSQL CRUD.
- Step-by-step Notes tutorial that traces requests, schema migrations and tests.
- A GitHub-sourced one-command `npx` path, without claiming that a registry package has been published.
- Cross-platform generation and disposable PostgreSQL E2E integration checks.
- Release readiness, security/support and community feedback documentation.

## Previous completed milestones on main

- F2B: MIT license, beginner-first README, getting-started and contribution guides, generated license preservation.
- F2A: optional PostgreSQL + Drizzle schema, connection, migrations and disposable DB tests.
- F1D: support for choosing a separate output directory.
- F0–F1C: React/Vite + Express/TypeScript starter, shared Zod contracts, CLI generation, lint, build, tests and Windows/Linux CI.

See GitHub pull requests for exact historical commits and tested changes.
