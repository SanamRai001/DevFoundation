    NEXT, RUN THE REAL THING

    From preview to real code

    Install Node.js 24 and Git, then run this in a terminal. The generated project includes a real Express API with temporary in-memory storage—no PostgreSQL setup needed.

    npx --yes github:SanamRai001/DevFoundation beginner-notes --example notes

    Then run cd beginner-notes followed by npm run dev. Open http://127.0.0.1:5173. Want persistent data later? Follow the PostgreSQL walkthrough.
