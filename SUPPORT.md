# Support

DevFoundation is a volunteer-maintained open-source starter, not a hosted service or a guaranteed support contract.

## Getting unstuck

1. Read the [beginner guide](docs/GETTING_STARTED.md) and [Notes walkthrough](docs/BUILD_A_NOTES_APP.md).
2. Check your Node version (`v24.x`), directory, and command.
3. Run `npm run doctor` in the DevFoundation repository or `npm run check` in a generated project.
4. Search [existing issues](https://github.com/SanamRai001/DevFoundation/issues) before filing a new one.

For bugs, open an issue with the operating system, Node/npm versions, exact nonsecret command, expected outcome, actual outcome, and reproduction steps. **Never** paste `.env`, access tokens, personal data or DB credentials into issues/logs.

Feature requests and beginner documentation improvements are welcome. No guaranteed response time is promised.

## Security reports

Please consult [SECURITY.md](SECURITY.md) for sensitive security issues. Avoid posting exploitable details publicly.
